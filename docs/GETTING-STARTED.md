# Getting started

Prerequisites: Node.js 20+, pnpm 9+.

1. Install dependencies with `pnpm install`.
2. Copy environment templates when added; never use production credentials locally.
3. Start the selected app with `pnpm --filter <workspace-name> dev`.

The repository is being established in stages. The initial commit introduces the product definition and workspace conventions; application packages and infrastructure are added incrementally. See [Delivery roadmap](DELIVERY-ROADMAP.md).

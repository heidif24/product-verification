# PAN design system

## Brand character
Confident, calm, precise and welcoming. PAN should feel like trusted infrastructure presented with the care of a premium consumer product. Avoid visual noise, alarmist fraud language and generic enterprise-dashboard styling.

## Core palette
- Forest: #173B32 — primary brand, navigation anchors and primary actions.
- Deep forest: #214C40 — hover and emphasis.
- Sage: #A9C7B2 — supportive data and soft surfaces.
- Ivory: #F7F8F4 — application canvas.
- White: #FFFFFF — cards and working surfaces.
- Brass: #C59A58 — restrained accent, never the main status colour.
- Ink: #202B27 — primary text.
- Muted: #87928C — secondary text.

## Typography
Manrope for display and section headings; DM Sans for interface and body text. Use system fallbacks. Keep type hierarchy compact and readable.

## Principles
1. Clarity before decoration.
2. Calm status communication: green for healthy, amber for review, red only for genuinely critical states.
3. Consistent 8px spacing rhythm, subtle borders, soft radii and restrained shadows.
4. Responsive from small phones upward; keyboard access and visible focus states.
5. Charts must have labels and never rely on colour alone.
6. Consumer verification should use plain language and explain what a result does and does not establish.

## Surface-specific direction
- Manufacturer: information-dense but breathable, clear operational hierarchy and useful analytics.
- Public verification: minimal steps, high legibility and no account barrier.
- Mobile: scan-first, thumb-friendly controls, calm feedback and no permission gate before verification.
